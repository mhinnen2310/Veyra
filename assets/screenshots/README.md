# Veyra native renderer screenshots

These images are authentic development captures of **Veyra's native renderer**, not examples of existing third-party shaderpacks. The five intended gallery files are:

| Filename | Scene |
| --- | --- |
| `native-water-reflections.png` | Daylight water reflections and transparency |
| `native-night-village.png` | Village lighting at night |
| `native-colored-light-interior.png` | Cyan local lighting from a sea lantern beneath an ender chest |
| `native-lava-at-night.png` | Lava lighting at night |
| `native-tinted-glass-experiment.png` | Experimental colored glass transmission |

The grass/foreground screenshot was not intended for publication and is **excluded**.

The gallery photos have not yet been uploaded into this GitHub folder. Keep original screenshots and label experimental glass as a work-in-progress: one frame does not establish correct refraction or image stability in motion.
