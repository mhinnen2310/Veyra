# Introducing Veyra — Minecraft graphics on Vulkan

I'm developing **Veyra**, an experimental Minecraft Java graphics project that combines its own native renderer with a Legacy renderer for existing shaderpacks on Vulkan.

The native renderer includes experimental ray-traced lighting, indirect illumination, reflections, water, materials and atmospheric effects. Veyra also integrates FSR-based reconstruction and optional frame generation.

For Legacy shaderpacks, I've deliberately narrowed testing to **four versions that currently launch, render and remain playable on my development PC**: Complementary Unbound, Sildur's Vibrant Shaders, MakeUp UltraFast and BSL. I'm expanding compatibility one pack at a time rather than claiming support for everything.

This is still an early development project, not a public release. I'm preparing a **limited closed alpha** to gather stability, image-quality and hardware feedback. Application details, a Discord invitation and more demonstrations will follow.

The screenshots in this repository show **Veyra's native renderer**, not the four external shaderpacks. All features and compatibility remain experimental.
